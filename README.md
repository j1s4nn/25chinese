### What changed in 4.3.2

- Assistant replies use plain, short lines with no oversized or brightly coloured headings; examples are numbered and stacked as Chinese / pinyin / English with matching colour.
- Grammar structure renders in a bordered box with coloured, bold verbs, adjectives and adverbs.
- Explain shows Chinese sentence, pinyin, natural meaning and another real-life example, followed by Meaning table and Grammar patterns buttons.
- Meaning table treats whole words, 3-4 character phrases and proverbs as one unit (e.g. 不用 = "no need / no use"), never single-character guesses.
- Each table row has a Note button that saves the unit to the permanent, deduplicated "new collection characters" notebook note.
- Extra study reveals the Chinese answer for English-to-Chinese cards instead of repeating the English.

Older installers stay on the Releases page for rollback. Every release ships the installer and a checksum file so you can verify the download before installing. The app updates itself from the signed update feed.

Source code is not published in this repository.
