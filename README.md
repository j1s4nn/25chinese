### What changed in 4.3.2

- Card assistant examples reply as stacked Chinese / pinyin / English, each with matching colour on the card character and its pinyin and meaning.
- Grammar structure renders in a bordered box with coloured, bold verbs, adjectives and adverbs, followed by numbered real-life examples.
- Legion explains whole words, phrases and proverbs instead of splitting characters, and never reports "meaning unavailable".
- Explain now offers Meaning table and Grammar patterns mini-buttons. Each table row has a Note button that saves the unit to the permanent, deduplicated "new collection characters" notebook note.
- Extra study now reveals the Chinese answer for English-to-Chinese cards instead of repeating the English.

Older installers stay on the Releases page for rollback. Every release ships the installer and a checksum file so you can verify the download before installing. The app updates itself from the signed update feed.

Source code is not published in this repository.
